Deploying the React client application to Vercel's global CDN

▲

Vercel Frontend Deployment

Connect repository rishav9631/my-job-portfolio & set environment variables

1

Log in to Vercel Dashboard with your GitHub account.

2

Click Add New... → Select Project.

3

Find repository rishav9631/my-job-portfolio and click Import.

4

Configure project build settings as follows:

Setting Value
Framework Preset Create React App
Root Directory ./ (Leave empty / project root)
Build Command npm run build
Output Directory build
5

Expand Environment Variables and add your Render backend URL:

Environment Key Value
REACT_APP_BASE_URL https://<your-render-backend-name>.onrender.com
6

Click Deploy and wait for the deployment process to complete (~1-2 minutes).

Pro-Tip for Step 4: CORS Authorization

Once Vercel gives you your live URL (e.g. https://my-job-portfolio.vercel.app), add it as CLIENT_URL in your Render service Environment tab so CORS requests succeed!
